# ProCalc - A Scientific Calculator

ProCalc is a modern scientific calculator built with HTML, CSS, and JavaScript. It offers various mathematical functions such as trigonometric, logarithmic, factorials, and basic arithmetic operations. The calculator features both dark and light modes for a more personalized experience, and it can be easily toggled with a button.

## Features

- **Basic Arithmetic Operations**: Addition, subtraction, multiplication, division.
- **Scientific Functions**: Sin, cos, tan, square root, power, logarithm (log and ln), and factorial.
- **Constants**: Use π (Pi) and e (Euler’s number) in calculations.
- **Clear & Delete Functions**: Easily clear the current input or delete the last character.
- **Responsive Design**: Works seamlessly on desktop and mobile devices.
- **Smooth UI**: The calculator has a visually appealing and modern design with smooth transitions and interactions.

## Installation

To use the calculator locally, you can follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/Bryt19/procalc.git
   ```

2. Open the project folder:
   ```bash
   cd procalc
   ```

3. Open the `index.html` file in your browser:
   ```bash
   open index.html  # MacOS
   start index.html # Windows
   ```

Alternatively, you can just open the `index.html` file in any browser.

## Usage

1. **Basic Operations**: 
   - Click the number buttons (0-9) to input numbers.
   - Use the operator buttons (+, -, *, /) for basic operations.
   - Click the `=` button to get the result of the operation.

2. **Advanced Functions**:
   - Use the scientific function buttons (sin, cos, tan, √, ^, log, ln, π, e, !) for advanced calculations.
   - The factorial (`!`) button computes the factorial of the number entered.

3. **Clear & Delete**:
   - The `C` button clears the input field.
   - The `DEL` button deletes the last entered character.

## Code Structure

- **`index.html`**: The main structure of the calculator, which includes buttons, input display, and the theme toggle button.
- **`styles.css`**: All the styles and themes, including the dark mode and light mode styles.
- **`script.js`**: JavaScript code that handles button clicks, performs calculations, and toggles between light and dark modes.
